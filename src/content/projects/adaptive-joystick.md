## Overview

An adaptive joystick designed for users with dyskinetic cerebral palsy. The housing accepts a family of swappable heads sized for different points of contact — a jumbo grip, a chin-control nub, an arm-strap mount — so the same input device can serve very different motor profiles.

## Modular heads

Each head bayonets onto the body in seconds. Sizing them as a family meant the underlying mechanism stays constant; only the contact surface changes. Jumbo for users with strong but imprecise grip, the chin nub for users without reliable hand use, the arm-strap mount for users who can swing an arm but can't pinch.

## Circuit

Makey Makey-style: each directional contact closes a high-impedance switch, which the host computer reads as an arrow key. No drivers, no calibration — plug it in, it works, which matters when the end user isn't going to want to troubleshoot a config file.

## Outcome

Functioning prototype with three head variants. The arm-strap version surprised the most — the assumption going in was that the jumbo grip would be the most useful, but the arm-strap was the one users wanted to keep trying.
